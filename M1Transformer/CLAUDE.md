# M1Transformer

## Start here for any debugging session

Before doing any debugging, investigation, or "why does this number look
wrong" work in this repo, read
[notes/debug/context.md](notes/debug/context.md) first. It defines how
debug sessions in this repo should be run (verify against ground truth,
check what's inherited from Torres's original code vs. introduced here,
check `notes/torres.pdf` for domain definitions, etc.) and indexes every
past dated debug log in `notes/debug/`, each of which may already contain
the answer to what's being asked.

At the end of any debugging session, add a new
`notes/debug/debugMMDDYYYY.md` log (see `notes/debug/context.md` for the
expected format) and add it to that file's session index.
